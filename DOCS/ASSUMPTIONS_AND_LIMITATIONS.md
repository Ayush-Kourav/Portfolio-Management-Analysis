# Assumptions & Limitations

- Portfolio capital is ₹100.58 Cr based on the holdings sheet.
- Benchmark is normalized to 100 for comparison.
- The supplied daily return observations cover only 10 days (1–10 July 2026).
- Annualized return and Treynor figures are illustrative and highly sensitive to the short sample.
- The source workbook contains a column labelled Beta that is calculated as stock 3-year CAGR divided by benchmark CAGR; this is retained as source information but is not used as statistical beta.
- Historical stock-selection inputs and benchmark assumptions are source-provided and should be independently refreshed for a live investment analysis.
