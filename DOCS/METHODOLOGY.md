# Portfolio Management Methodology

This project evaluates a simulated portfolio against a Nifty benchmark using supplied daily returns. Portfolio value is compounded from the actual holdings total of ₹100.58 Cr. The benchmark is normalized to 100 at the start of the observation period.

## Risk Metrics

Beta is calculated statistically as covariance of portfolio and benchmark daily returns divided by benchmark return variance. The original workbook's CAGR/benchmark-CAGR ratio is not treated as beta.

Treynor Ratio is shown as an illustrative annualized metric because only 10 daily observations are available; it should not be interpreted as a robust long-term estimate.
